# 📚 Studiûm - Приложение для изучения языков

Современное веб-приложение (PWA) для учеников, изучающих английский и испанский языки.

## 🎯 Возможности

### Для учеников:
- ✍️ **Дневник** - записи о процессе обучения
- 📖 **Словарик** - добавление и хранение слов с переводом
- 🎴 **Карточки** - повторение слов в формате флэшкарт
- ✅ **Тесты** - проверка знаний с выбором правильного перевода

### Для учителя:
- 👥 **Просмотр учеников** - доступ к дневникам и словарям всех учеников
- ➕ **Управление** - создание новых учеников с логином и паролем
- 📊 **Статистика** - количество записей и слов у каждого ученика

## 🚀 Быстрый старт

### Вариант 1: Запуск на компьютере (самый простой)

1. **Скачай все файлы** в одну папку
2. **Открой файл `index.html`** в браузере (Chrome, Firefox, Safari)
3. **Готово!** Приложение работает

**Вход для учителя:**
- Логин: `teacher`
- Пароль: `teacher123`

### Вариант 2: Публикация в интернет (бесплатно)

#### Через GitHub Pages (рекомендуется):

1. Зарегистрируйся на [GitHub.com](https://github.com)
2. Создай новый репозиторий (Repository)
3. Загрузи все файлы приложения
4. Зайди в Settings → Pages
5. Выбери ветку `main` и папку `/ (root)`
6. Сохрани - через минуту приложение будет доступно по адресу: `https://твой-логин.github.io/название-репозитория`

#### Через Netlify:

1. Зайди на [Netlify.com](https://netlify.com)
2. Нажми "Add new site" → "Deploy manually"
3. Перетащи папку с файлами
4. Готово! Получишь ссылку типа `https://random-name.netlify.app`

## 👨‍🏫 Как пользоваться (для учителя)

### Добавление учеников:

1. Войди как учитель (`teacher` / `teacher123`)
2. Перейди во вкладку "⚙️ Управление"
3. Заполни данные ученика:
   - **Имя**: как будет отображаться
   - **Логин**: для входа (например, `ivan`)
   - **Пароль**: простой пароль (например, `ivan123`)
   - **Язык**: что изучает ученик
4. Нажми "Добавить ученика"
5. **ВАЖНО:** Запиши или скопируй логин и пароль - дай их ученику

### Просмотр данных ученика:

1. Во вкладке "👥 Ученики" нажми на карточку ученика
2. Откроется окно с его дневником и словариком
3. Можешь посмотреть все записи и слова

## 👨‍🎓 Как пользоваться (для ученика)

1. **Войди** с логином и паролем, которые дал учитель
2. **Дневник**: пиши что изучал, какие сложности
3. **Словарик**: добавляй новые слова с переводом
4. **Карточки**: повторяй слова - нажимай на карточку чтобы увидеть перевод
5. **Тест**: проверяй себя - выбирай правильный перевод

## 🔧 Техническая информация

### Где хранятся данные?

**Сейчас:** Все данные хранятся в браузере (LocalStorage)
- ✅ Работает сразу, без настройки
- ✅ Полностью бесплатно
- ⚠️ Данные привязаны к одному устройству
- ⚠️ При очистке кэша браузера - данные удалятся

### Хочешь синхронизацию между устройствами?

Можно подключить Firebase (бесплатно для 15 учеников):

1. Зайди на [Firebase Console](https://console.firebase.google.com)
2. Создай новый проект
3. Добавь "Realtime Database"
4. В файле `database.js` замени конфигурацию в начале файла
5. Подробная инструкция будет отдельно, если понадобится

## 🛠️ Что делать если...

### Забыл пароль ученика?
Войди как учитель, удали ученика и создай заново с новым паролем

### Приложение не работает?
Проверь что все файлы в одной папке и открываешь именно `index.html`

### Хочу изменить дизайн?
Открой файл `styles.css` - там все цвета и стили. Можешь поменять цвета в начале файла (`:root`)
